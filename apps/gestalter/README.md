# gestalter

A personal learning and note-taking app: views as tabs, with the note views always there and others installable. On
the web it is the web app's `/notes` ([`../web`](../web)), on the home store in the browser. On Android it's the page
the app wraps (`distribution-android/`, [`../node/doc/android.md`](../node/doc/android.md)): `mise run android:dev`.
