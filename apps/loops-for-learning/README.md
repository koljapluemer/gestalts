# loops-for-learning

The learning views from `distribution.yml`, one at a time, as a static site. Its data stays in the browser's `loops`
repository and can optionally sync through the desktop app. Every plugin tagged `learning` listed there becomes a tab.
New learning views are made in [learning-workshop](../learning-workshop).

From the repo root: `mise run loops:dev` (:5174, hot reload), `mise run loops:build` (static files in `dist/`).
