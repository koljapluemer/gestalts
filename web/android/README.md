# android

The page the Android app wraps: gestalter (notes and installable views in tabs) on the phone's folder, which syncs
with a paired desktop node. On the web, gestalter is the web app's `/notes` ([`../app`](../app)). The app itself (the
Tauri shell: sync, pairing, the commands) is folder-sync's, see
[`../../installables/folder-sync/doc/android.md`](../../installables/folder-sync/doc/android.md): `mise run android:dev`.
